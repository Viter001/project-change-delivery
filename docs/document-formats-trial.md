# 文档版式验证

日期：2026-11-05；版本：0.4.2。

用户指出 Q 中仍有日期型“决策记录”和补充流水，进一步要求覆盖其他文件。本轮提供统一版式参考，覆盖 README、规划、规范、指南、Q、Feedback、DEVLOG、DISCUSSION-LOG、验收、agent checkpoint 与派生视图。入口要求更新文档前读取对应格式。

独立代理只读技能与必要参考，对含日期补充的 Q、待复验反馈、重复开发事件、讨论、README 排错全文、跨版本验收和长卷 checkpoint 做纸上整理。实际输出将 Q／FB 改为当前字段、阶段成果合并、讨论按轮次、验收区分版本、checkpoint 替换为当前现场；没有把测试通过推定成人工验收，也没有编造缺失的批准来源。

试验发现通用标题约束与 DEVLOG 日期标题有歧义，已明确日志和版本验收的例外；按具体模板逐项核对后无相反要求。结构校验、包内引用与文件一致性、差异格式检查通过。此为一个独立上下文的纸上试验，未证明长期多模型行为，也未在本轮自动迁移业务项目的全部历史文件。

版式规范以 `project-change-delivery/references/document-formats.md` 为主记录；本页仅保存验证范围。已安装版本备份位于本项目运行目录。
