# 交付与交接

## 缺失文件的建立规则

在具体项目内检查管理职责，复用已有等价文件或可访问系统，并在入口留定位链接。缺少相关载体时建立有标题、用途、字段和已知事实的占位文件，未知项写待补充／未验证。

| 职责 | 默认载体 | 内容 |
| --- | --- | --- |
| 目标与状态 | README.md | 目标、范围、阶段、管理入口 |
| 重要裁决 | QUESTIONS.md | 决策、影响、来源、落实状态 |
| 当前整改 | FEEDBACK.md | 当前清单、详情、验收及关联决定 |
| 阶段成果 | DEVLOG.md | 成果、验证、限制、引用 |
| 对话复盘 | DISCUSSION-LOG.md | 实质轮次、用户要求、处理、结果 |
| 验收 | docs/acceptance.md | 条件、方法、版本／环境、结果、证据 |

专项管理文件随实际职责建立。代码 Review 放对应 PR 或本地相关事项的评审栏。旧文件按内容判断职责，迁移保留来源和编号映射，见 [管理记录](management-records.md)。

## 完成证据

| 声明 | 所需依据 |
| --- | --- |
| 已实现 | 实际成果及适用范围 |
| 已验证 | 必要检查通过及版本、环境、范围 |
| 用户已验收 | 用户的相应确认 |
| 已发布／发送 | 实际外部动作和结果 |

各状态独立记录。整理文档完成仅说明整理成果；历史证据说明历史状态。必要检查失败或未运行时说明阻碍及进度。验收邀请按 [注意力原则](project-attention.md) 筛选。

交付记录包括目标、改变、关键决定、证据、剩余影响和成果位置。决策变更保留取代关系；当前状态随有效成果更新。接手续读 [协作与接手](collaboration-and-handoff.md)，执行现场依 [记录分层](record-layers.md) 保存。
