# 变更分级与验证选择

仅在影响面不明确、任务涉及多个成果或共享规则时阅读。以下用于选择必要工作，不要求填写固定表单。

## 从结果与依赖判断

| 问题 | 对处理方式的影响 |
| --- | --- |
| 用户可见结果或对外承诺是否变化？ | 明确旧行为与目标行为，并检查相关说明 |
| 是否有其他使用方共享同一机制？ | 沿直接依赖选择代表性回归，不能以文件数限制范围 |
| 是否改变标识、结构、公式含义或输入输出？ | 检查引用、兼容、历史数据与下游消费方式 |
| 失败能否迅速恢复？是否影响真实用户或不可重建数据？ | 在执行前准备与风险相称的恢复措施，并核对授权 |
| 当前检查实际覆盖什么？ | 将未覆盖的必要验收补齐；不要仅引用通过数量 |

不使用固定分数决定等级。同一次改动可有不同部分：局部排版按轻量处理，共享计算规则按较高影响处理。

## 跨项目示例

| 请求 | 主要影响 | 合适验证 |
| --- | --- | --- |
| 修改报告一个标题 | 标题、目录或交叉引用 | 核对最终显示与相关引用，更新验收记录、开发记录并中文提交；缺失管理文件先补齐 |
| 调整共享文档模板 | 多份导出物、分页、字体 | 代表性短文与长文导出，检查实际版面 |
| 调整表格费率公式 | 全部引用公式、汇总和历史解释 | 典型与边界输入、汇总对账；精确金额用精确断言 |
| 修改界面事件处理 | 点击、键盘、拖动、取消 | 真正操作受影响输入路径；单个按钮通过不代表共享机制通过 |
| 替换内容素材 | 来源、授权范围、引用与展示 | 保留原件，检查派生记录、链接和最终产物 |
| 调整活动时间 | 邀请、议程、场地与参与方 | 核对获批准时间与相关材料；准备材料不自动授权发通知 |

## 断言与证据的粒度

- 精确契约使用精确检查：标识、金额、映射、明确批准的文本不能随意改成范围。
- 可调表现使用有意义的区间或行为检查：布局不溢出、动画可重复、时长在约定范围。范围必须来自目标，不能为通过测试临时放宽。
- 就绪条件应匹配任务：可操作状态、关键数据到位或最终文件生成，而不是任意等待时长或无关资源全部下载。
- 技术成功不替代效果判断：音频播放状态不证明可听，文件生成不证明可读，数据条数正确不证明口径正确。
- 模拟环境与实际设备分开报告；本次定向通过与历史全量通过分开报告。

## 发现失败之后

保留失败现象与范围；先核对是否仍符合当前批准的需求，再决定修实现、修检查还是补环境。将旧问题称为“既有”需要旧版本复现或明确历史证据；仅凭前任说法应标为待核实。

既有问题若阻断当前交付目标，仍是交付阻碍。与目标无关且不影响验收的，不必无限扩展修复；记录影响与下一步即可。临近截止时间不改变证据含义。
