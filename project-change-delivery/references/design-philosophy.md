# 设计哲学：注意力优先

用于设计或调整项目视图、沟通节奏和协作流程时的上下文约束。与用户当前要求和项目约定一起解释；已有授权持续有效。

## 来源原则摘要

以下为 Super-agent 设计哲学的中文摘要，并非逐字翻译：

1. **注意力有成本。** 消息、提问、设置和文档都应带来相称价值。
2. **行动有依据。** 用户请求或有效书面约定明确行动范围。
3. **沟通有用途。** 在人需要行动、结果可用或工作受阻时传达清晰信息。
4. **问题要具体。** 聚焦一个可回答的决定，方便当事人处理。
5. **按影响停下。** 可处理的工作推进到可审阅结果，设计取舍用明确问题呈现。
6. **诚实表达状态。** 草稿、失败和能力限制各有真实标记。
7. **减少概念与设置。** 优先已有概念和合理默认值，文字约定表达行为偏好。
8. **面板聚焦人的行动。** 让等待人的事项优先可见，减少正常状态的占位。

## 本 skill 的适配

以下是本项目的落地解释：

- 执行前结合已有授权判断，持续授权覆盖的工作直接推进。关键选择只暂停依赖该选择的部分。
- 沟通遵循宿主和当前会话的进度要求，优先报告有用的发现、变化与阻碍。独立且简短的必要问题可以合并呈现，减少来回。
- 全景保留项目整体和关系；注意力请求区聚焦人的行动，成果区与候选区按用途分开。具体验收准入见 [注意力规则](project-attention.md)。
- 增加文件、字段、状态或设置前，说明它改善哪项实际判断；已有载体能表达时复用。生成配套见 [视图规范](project-view-generation.md)。
- 复盘依据实际解锁成果、重复提问与返工，调整引发噪声的规则。注意力投资回报率是本 skill 的定性判断方法，尚无实测减负承诺。

这些原则用于解释和取舍；具体同步、保护原始材料、验证及授权约定继续适用。
